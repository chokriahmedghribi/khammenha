# خمّنها — لعبة الكلمات العربية

لعبة تخمين كلمة عربية: اختر طول الكلمة من 3 إلى 7 أحرف (عدد المحاولات = عدد الحروف + 1)، بالعربية (من اليمين لليسار).

## المزايا
- 📅 كلمة اليوم (تتغير عند منتصف الليل) + 🎲 لعب مفتوح بلا حدود
- ألوان: أخضر (مكان صحيح) / أصفر (مكان خاطئ) / رمادي (غير موجود)
- 💡 تلميح ×2 يكشف حرفًا من الكلمة، و🎯 عين الصقر ×1 يكشف حرفًا في مكانه
- إحصائيات: عدد الألعاب، نسبة الفوز، السلسلة، أفضل سلسلة، توزيع المحاولات
- مشاركة النتيجة بالمربعات الملونة، عدّاد للكلمة التالية، احتفال بالقصاصات
- الوضع الليلي، الوضع الصعب، الاهتزاز
- يعمل بدون إنترنت

## بناء ملف APK

### الطريقة 1: Android Studio
افتح المجلد في Android Studio ← انتظر مزامنة Gradle ← Build ← Build APK(s).

### الطريقة 2: من الهاتف عبر GitHub (بدون حاسوب)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه محتويات هذا المجلد.
2. يعمل البناء تلقائيًا (تبويب **Actions** ← Build APK).
3. بعد انتهائه، حمّل `Khammenha-apk` من أسفل صفحة التشغيل، فكّ الضغط وثبّت الـ APK
   (فعّل «التثبيت من مصادر غير معروفة»).

## التعديل
- اللعبة كلها في `app/src/main/assets/index.html`.
- لإضافة كلمات: عدّل `WORDS_BY_LEN` في نفس الملف (القائمة حسب عدد الحروف، الهمزات أ/إ/آ تُكتب «ا»).
- اسم التطبيق: `app/src/main/res/values/strings.xml`.
